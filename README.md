# Cálculo del total de una compra

Este proyecto contiene un programa sencillo desarrollado en Python
que calcula el total de una compra utilizando una función.

## Funcionamiento

La función `calcular_total(precio, cantidad)` recibe dos parámetros:

- `precio`: precio del producto.
- `cantidad`: cantidad de productos.

El programa multiplica ambos valores y retorna el total de la compra.

## Ejemplo

Si el precio es 10 y la cantidad es 3:

10 × 3 = 30

El resultado mostrado en consola es:

El total de la compra es: 30
